# Security

This repository is a **public** Nuxt house template. It must not contain secrets.

## Do not commit

- Real `.env` files (only `.env*.example` are tracked)
- TLS keys/certs (`.certs/`, `*.pem`, `*.key`)
- Cloud credentials, OIDC role ARNs for personal accounts, tokens, or private hostnames

## Reporting

If you find a credential or private data in this repo or its history, open a private security advisory or contact the owner and rotate the secret immediately.
